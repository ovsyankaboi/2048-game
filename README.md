# Игра 2048

Учебный проект по реализации классической игры **2048** на чистом HTML, CSS и JavaScript без использования фреймворков.

## Функциональность

- Игровое поле 4×4, генерируемое динамически.
- Движение плиток во всех направлениях (↑ ↓ ← →) с корректным суммированием очков.
- Добавление новых плиток (2 или 4) в случайные свободные клетки после каждого хода.
- Подсчёт и отображение текущего счёта.
- Кнопки **Новая игра** и **Отменить ход (undo)**.
- Проверка окончания игры (нет возможных ходов).
- Сохранение текущего состояния игры в `localStorage` и восстановление при перезагрузке страницы.
- Таблица рекордов (топ-10) с сохранением в `localStorage`.
- Управление с клавиатуры (стрелки) и виртуальными кнопками на мобильных устройствах.
- Адаптивная вёрстка под десктоп, планшеты и смартфоны.
